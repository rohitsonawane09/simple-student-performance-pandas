# 📊 Student Performance Analysis using Pandas

A beginner-level data analysis project using **Python and Pandas** to explore and analyze a student performance dataset.

This project was created as part of my journey from learning Python and NumPy toward Data Analytics.

---

## 🎯 Project Objective

The objective of this project is to practice using **Pandas** to load, explore, filter, sort, transform, and analyze a student performance dataset containing information about students, their study habits, attendance, participation, and academic performance.

---

## 🛠️ Technologies Used

- Python
- Pandas
- Jupyter Notebook

---

## 🧠 Key Learning

Through this project, I learned how to use **Pandas** for working with structured datasets.

### Pandas Concepts Practiced

- Loading datasets using Pandas
- Working with DataFrames
- Selecting columns
- Filtering rows
- Sorting data
- Finding maximum and minimum values
- Creating calculated columns
- Applying conditional logic
- Performing basic data analysis

### Main Takeaway

The main lesson from this project was understanding how Pandas can be used to work with **rows and columns efficiently** instead of processing individual values manually.

This project helped me strengthen my **Pandas fundamentals** and prepared me for the next stage of my Data Analytics learning journey.
